# 🥚🔫 Eggs and Guns

A 2D top-down shooter built in Unity (C#) — originally created as a college project, with ongoing improvements planned.

---

## 🎮 About the Game

**Eggs and Guns** is a fast-paced 2D action shooter where chicken must defend herself using eggs. The project serves as a hands-on demonstration of core Unity game development concepts including player movement, shooting mechanics, enemy AI, and custom shader effects.

---

## ✨ Features

- 🎯 2D shooter / action gameplay
- 🖌️ Custom shaders and visual effects (ShaderLab / HLSL)
- 🕹️ Player movement and shooting mechanics
- 👾 Enemy behaviour and interactions
- 🧩 Modular Unity project structure

## 🚀 Getting Started

### Prerequisites

- [Unity Hub](https://unity.com/download) installed
- Unity Editor **6 or later** (recommended)
- Visual Studio or VS Code (optional, for script editing)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/romanButkus/EggsAndGunsGame.git
   ```

2. **Open in Unity Hub**
   - Launch Unity Hub
   - Click **Open** → **Add project from disk**
   - Navigate to the cloned folder and select it

3. **Open the project**
   - Unity will import all assets automatically
   - Open the main scene from the `Assets/Scenes/` folder

4. **Press Play** in the Unity Editor to start the game
